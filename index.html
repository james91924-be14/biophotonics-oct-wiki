🔬 動手玩光學：OCT 軸向解析度與雷射安全互動計算機

拉動滑桿，即時體驗中心波長 $\lambda_0$、頻譜半高寬 $\Delta\lambda$ 如何決定微米級軸向解析度 $\delta z$ 與入眼安全狀態！

公式：$\delta z = \frac{2\ln 2}{\pi}\frac{\lambda_0^2}{\Delta\lambda}$，生物組織折射率取 $n \approx 1.38$。

生物組織內理論軸向解析度 ($\delta z / n$)
3.49 μm (空氣中 4.81 μm)

🌟 1045nm 波段兼具低 RPE 散射與 3.5 微米級高解析度，最適合後鞏膜雙折射成像！

✅ 環安衛檢核通過：入眼功率 1.4 mW 符合 ANSI Z136.1 安全上限 (≤ 1.8 mW)。

CARD 01 // 雷射安全

為什麼 1045nm 雷射看不見光，進暗房卻規定一定要戴 OD 5+ 護目鏡？

✅ 因為 1045nm 是近紅外光（NIR），可穿透角膜直達眼底，但人眼無法感知、不會觸發眨眼反射，極易造成視網膜熱損傷！
👆 點擊卡片翻面看解答
CARD 02 // 光纖維護

APC 斜面光纖跳線端面髒了，可以用一般衛生紙沾酒精擦拭嗎？

✅ 絕對不行！衛生紙纖維粗糙會刮傷 8 度斜面鍍膜。必須使用 Cletop 光纖專用清潔盒沿同一方向單向輕推！
👆 點擊卡片翻面看解答
CARD 03 // 振鏡同步

為什麼 200kHz OCT 的 X 軸鋸齒波要預留 15% Flyback 回掃緩衝區？

✅ 因為振鏡鏡片有轉動慣量，若用 0 微秒瞬間反轉會造成高頻機械振盪與驅動板過熱失步！
