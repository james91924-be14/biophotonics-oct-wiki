Q1 // 雷射安全

為什麼 1045nm 雷射明明看不見光，進暗房卻規定一定要戴 OD 5+ 護目鏡？

✅ 解答：因為 1045nm 是近紅外光（NIR），可穿透角膜直達視網膜與後鞏膜，但人眼視覺感知不到，被照到時「不會觸發眨眼反射」，極易造成永久視網膜熱損傷！
👆 點擊卡片翻面看解答
Q2 // 光機維護

APC 斜面光纖跳線端面髒了，可以用一般衛生紙沾酒精擦拭嗎？

✅ 解答：絕對不行！衛生紙纖維粗糙且會殘留微粒刮傷 8 度角斜面鍍膜。必須使用 Cletop 光纖專用清潔盒，沿同一方向單向輕推一次！
👆 點擊卡片翻面看解答
Q3 // 訊號除錯

電腦畫面上的干涉波形突然變成一條水平直線，且 BPD 亮紅燈怎麼辦？

✅ 解答：這是平衡光電探測器（BPD）飽和了！請立即調降參考臂的可調光衰減器，使單臂功率回到 0.5 ~ 1.0 mW，切勿直接調大雷射主電流。
👆 點擊卡片翻面看解答
Q4 // AI 訓練禁忌

訓練 OCT 影像降噪模型時，把同一顆豬眼的 200 張切片隨機分給訓練集與測試集可以嗎？

✅ 解答：嚴格禁止！相鄰 B-scan 切片解剖結構高度相似，隨機切分會造成嚴重的「資料洩漏 (Data Leakage)」，必須以「不同樣本個體」為單位切分！
