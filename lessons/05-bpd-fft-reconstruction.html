1. 平衡光電探測器 (BPD)：為什麼要把干涉光分成兩路相減？

從豬眼後鞏膜反射回來的樣品光極度微弱（通常只有幾十奈瓦 $\text{nW}$），如果直接用單一光電二極體接收，微弱的干涉訊號會被掃頻雷射本身的直流背景光（DC Term）與相對強度雜訊（Relative Intensity Noise, RIN）完全淹沒！

⚡ 差動相減放大機制（Balanced Detection）：
當樣品光與參考光在 $50/50$ 光纖耦合器合光時，根據能量守恆與相位關係，兩條輸出光纖的干涉交流項（AC Term）剛好相位相差 $180^\circ$（一正一負），而直流背景項則同號： $$I_+(k) = I_{\text{DC}}(k) + 2\sqrt{I_R I_S}\cos(2k\Delta z)$$ $$I_-(k) = I_{\text{DC}}(k) - 2\sqrt{I_R I_S}\cos(2k\Delta z)$$ BPD 將兩路光電流直接相減 $\Delta I = I_+ - I_- = 4\sqrt{I_R I_S}\cos(2k\Delta z)$，一舉消除共模強度雜訊並將有用干涉訊號放大 2 倍！

2. 波長 $\lambda$ 轉波數 $k$ 重取樣：為什麼直接做 FFT 會模糊？

快速傅立葉轉換（FFT）要求輸入的干涉訊號必須在波數空間（Wavenumber, $k = \frac{2\pi}{\lambda}$）呈等間距線性分布，才能精確對應到空間深度 $z$。

然而，掃頻雷射隨時間 $t$ 掃描波長 $\lambda(t)$ 時是非線性的，且 $k$ 與 $\lambda$ 成反比關係（$\Delta k \approx -\frac{2\pi}{\lambda_0^2}\Delta\lambda$）：

解決方案運作機制優缺點比較
方法 A：硬體 k-clock 觸發利用雷射內建馬赫-曾德爾干涉儀產生等 $\Delta k$ 脈衝，直接作為 DAQ 外接取樣時脈無須事後軟體插值、運算最快；但若時脈線接觸不良會產生橫向條紋偽影
方法 B：軟體數值重取樣 (k-space Resampling)先以反射鏡校正檔提取非線性相位曲線，再用三次樣條插值（Cubic Spline）重取樣為等 $k$ 陣列可精細修正非線性誤差，但每條 A-scan 皆需插值運算

3. 數值色散補償、漢寧窗與 MATLAB FFT 重建流程

因為參考臂（空氣／光纖）與樣品臂（90D 透鏡＋眼球玻璃體＋角膜）的材質厚度不同，不同波長的光波傳播速度不一致，會造成色散展寬（Dispersion Broadening），使斷層邊界變糊。我們在 MATLAB 中乘上複數相位補償項來抵消二階（$a_2$）與三階（$a_3$）色散：

$$S_{\text{comp}}(k) = S(k) \cdot \exp\Big[-i\big(a_2(k-k_0)^2 + a_3(k-k_0)^3\big)\Big]$$
% MATLAB 實驗室 SS-PS-OCT 單通道深度重建核心流程 win = hanning(N_k); % 1. 產生漢寧窗抑制旁瓣偽影 (Side-lobes) disp_phase = exp(-1i * (a2*dk.^2 + a3*dk.^3)); % 2. 建立數值色散補償相位陣列 k_sig_H = (raw_H - mean(raw_H)) .* win .* disp_phase; % 3. 去直流、加窗與色散校正 aline_H = fft(k_sig_H, N_fft); % 4. 快速傅立葉轉換取得深度複數結構 E_H(z)
