1. 為什麼 OCT 影像總是有顆粒狀的「散斑雜訊 (Speckle)」？

當我們觀察視網膜或後鞏膜的 OCT 斷層圖時，常會看到整張影像佈滿黑白相間的顆粒狀斑點，這稱為同調散斑雜訊（Coherent Speckle Noise）。

🌊 散斑的物理成因（Multiplicative Noise）：
因為在單一解析度體積（Voxel，約數微米大小）內，存在許多比波長還小的膠原纖維微粒。這些次解析度散射體反射回來的同調光波具有隨機相位差，彼此發生隨機的建設性或破壞性干涉，形成乘性散斑雜訊： $$I_{\text{observed}}(x,z) = I_{\text{true}}(x,z) \cdot n_{\text{speckle}}(x,z) + n_{\text{shot}}(x,z)$$

散斑會模糊視網膜層界線，並干擾 PS-OCT 的雙折射相位延遲斜率計算，因此「散斑抑制」是生醫光電影像處理最重要的課題。

2. 傳統多張平均法 vs. 深度學習 U-Net / CNN 單張降噪

過去為了消除散斑，硬體上會對同一個眼球位置重複掃描 $N$ 張 B-scan（例如連續拍 16 張或 32 張）再做算術平均，使訊噪比提升 $\sqrt{N}$ 倍。但在活體臨床上，人眼會不自主微顫動（Micro-saccades），拍太久反而會造成殘影模糊！

降噪策略輸入資料優勢與臨床限制
傳統多幀平均 (Frame Averaging)同一位置連續掃描 16~32 張 B-scan物理真實性最高；但掃描時間長，活體眼球移動會導致疊圖模糊
監督式 U-Net / ResNet單張高雜訊圖 $\rightarrow$ 映射至多張平均乾淨圖推論僅需數毫秒，單次掃描即可獲得媲美 16 張平均的高清斷層圖
自監督 Noise2Noise / 擴散模型成對獨立雜訊切片或條件式生成無須取得完美 Ground Truth 即可訓練，需注意保留微細血管邊界

3. 生醫 AI 訓練最高天條：嚴防資料洩漏 (Data Leakage)

在用 Python（PyTorch / Scikit-Learn）訓練 OCT 影像分類或降噪模型時，初學者最容易犯下導致論文被直接退稿的致命錯誤——切片級隨機切分（Slice-level Random Split）！

🚫 為什麼不能用 train_test_split(all_bscans)？
一顆豬眼或病患的 3D C-scan 體積包含 200 張相鄰的 B-scan 切片（彼此間隔僅幾微米，解剖結構幾乎一模一樣）。如果把全部切片混在一起隨機抽 80% 訓練、20% 測試，模型其實只是「背下了這顆眼球的長相」，測試集準確率會虛高到 99%，但遇到新病患就完全失效！
# Python 正確切分示範：使用 GroupShuffleSplit 以「眼球個體 (subject_id)」為單位隔離 from sklearn.model_selection import GroupShuffleSplit splitter = GroupShuffleSplit(n_splits=1, test_size=0.2, random_state=42) train_idx, test_idx = next(splitter.split(X_images, y_labels, groups=subject_ids)) # 確保同一顆眼球的切片絕對不會同時出現在 train 與 test！
