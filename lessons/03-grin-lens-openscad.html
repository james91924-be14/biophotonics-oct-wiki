1. 為什麼需要 GRIN 梯度折射率透鏡微探頭？

傳統球面透鏡依賴「表面曲率」來折射光線，體積較大且難以直接與直徑僅 $125\ \mu\text{m}$ 的單模光纖（SMF）貼合。在內視鏡 OCT 或深層組織微創探頭中，我們採用梯度折射率透鏡（Gradient-Index Lens, GRIN Lens）。

🔬 GRIN Lens 徑向拋物線折射率分布公式： $$n(r) = n_0 \left(1 - \frac{1}{2} g^2 r^2\right)$$ 其中 $n_0$ 為圓柱中心軸折射率，$r$ 為徑向距離，$g$ 為梯度常數。光線在 GRIN 透鏡內部會沿著正弦曲線平滑彎曲（Self-Focusing），一個完整正弦週期的長度稱為一個節距（Pitch, $P = \frac{2\pi}{g}$）。

透過精準裁切不同節距（如 $0.23\text{ Pitch}$ 或 $0.25\text{ Pitch}$）並搭配玻璃隔片（Glass Spacer），即可在平面端面上直接實現光束準直或微米級聚焦！

2. 微光學探頭組裝與 UV 光學膠固化 SOP

在組裝毫米級 GRIN 內視鏡探頭與中繼透鏡（Relay Lens）時，任何微小的角度偏移或膠水溢流都會造成嚴重的回光損耗與像差：

操作工序標準作業規範 (SOP)禁止事項與風險提示
透鏡夾持與對位必須使用鐵氟龍或陶瓷尖頭鑷子搭配五軸微調架對光嚴禁使用金屬硬質鑷子直接夾持 GRIN 圓柱邊緣，極易崩角碎裂
UV 光學膠點塗使用微量點膠針頭沾取極少許 UV 膠，利用毛細現象均勻填滿端面避免膠水溢流至透鏡側面改變邊界條件，或產生氣泡造成強散射
同軸對準與固化先開啟低功率對光光源並即時監測返回干涉訊號峰值，再分次照射 UV 燈切勿在未確認光軸同心度前直接高強度曝光鎖死

3. OpenSCAD 參數化光學探頭外殼與微流體治具建模

為了固定 90D 眼底鏡、13mm 四分之一波片（QWP）以及製作微流體器官晶片（Organ-on-a-chip）U 型流道模具，本實驗室採用純程式碼建模工具 OpenSCAD 進行 FDM / SLA 3D 列印：

// OpenSCAD 實驗室光學轉接環標準參數範本 $fn = 120; // 強制設定高圓弧細分度，防止圓孔退化為多邊形卡死鏡筒 lens_diameter = 13.0; tolerance = 0.18; // 預留 +0.15 ~ +0.20 mm 3D 列印熱脹冷縮公差 difference() { cylinder(h = 8.0, d = lens_diameter + 6.0); translate([0, 0, -0.1]) cylinder(h = 8.2, d = lens_diameter + tolerance); }
  • 材質與顏色規範：所有光路外殼與探頭套筒一律使用消光黑（Matte Black）線材或樹脂列印，防止 1045nm 近紅外光於內壁產生漫反射雜散光。
